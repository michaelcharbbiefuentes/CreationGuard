# CreationGuard

CreationGuard is a focus and productivity application designed to help users stay focused on creating, developing, or studying.

The application tracks time spent on potentially distracting activities such as gaming, social media, scrolling, and unrelated video browsing.

## Goal

The goal of CreationGuard is to encourage users to spend more time creating, developing, learning, and studying instead of consuming distracting content.

## Planned Features

- Focus session tracking
- Pause and resume sessions
- Session history
- Daily distraction limit
- Track distracting activities
- Detect games and distracting websites
- Automatically block or close distracting activities when the daily limit is reached
- Usage dashboard
- Daily productivity statistics
